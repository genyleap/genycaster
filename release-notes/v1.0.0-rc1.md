# Genycaster v1.0.0-rc1

## Features

- After verified 24-word Farcaster recovery, optionally authorize a per-device Ed25519 signer using a one-shot EIP-712 KEY_ADD and SignedKeyRequest.
- Require explicit, localized device-signer consent before native signer authorization.
- Bind temporary custody authorization to the verified FID and custody address, expire it within three minutes, and zeroize custody material after a single authorization attempt.
- Respect the user's explicitly selected write and signing provider. HyperSnap remains the default indexed reader, never a silent write-provider fallback.
- Verify signing compatibility against independent cryptographic vectors and keep regression tests on the GenyCaster server rather than in GitHub Actions.

## Security

- Never persist a Farcaster recovery phrase or custody private key. Network confirmation and a secure per-device signer vault remain required.
