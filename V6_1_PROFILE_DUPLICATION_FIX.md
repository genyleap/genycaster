# Genycaster V6.1 — Profile Duplication Fix

The Trust Score profile widget is now owned exclusively by the right Context Rail.

The left navigation no longer embeds `ProfileTrustCard`. `SidebarProfileSummary` has been restored to a compact account affordance containing only the avatar, display name, handle, verified state, and profile/account action.

This prevents duplicate Trust Score / Following / Followers information while keeping fast account access in the navigation shell.
