This directory contains:

- lottie/emoji_u*.json        — the bundled bootstrap Lottie assets (CC BY 4.0).
- noto_manifest.json          — a snapshot of the upstream noto-emoji-animation
                                api.json (icon identifiers, Unicode codepoints,
                                categories and tags) used to drive the emoji
                                catalog and provider asset mapping.
- bootstrap_manifest.json     — GenyCaster's configurable bootstrap set with
                                pinned sha256 checksums.
