# Contextual Reaction System

The primary lightweight reaction can use a topic-aware glyph while preserving the same action semantics.

| Content mentions | Glyph |
| --- | --- |
| Farcaster / FC / Warpcast | `brands/farcaster` |
| C++ / CPP | `tech/cplusplus` |
| Linux | `brands/linux` |
| Bitcoin / BTC | `crypto/bitcoin` |
| ETH Base / Base Chain | `crypto/base` |
| Quilibrium | `quilibrium/quilibrium` |
| QStore | `quilibrium/qstore` |
| No recognized topic | `actions/heart` |

The matcher is deterministic and priority-based. Short aliases must use token boundaries, not raw substring matching.
