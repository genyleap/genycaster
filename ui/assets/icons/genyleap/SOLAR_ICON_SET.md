# Solar Icon Set attribution

GenyCaster vendors selected SVG glyphs from the **Solar Icon Set** by 480 Design.

- Upstream: https://github.com/480-Design/Solar-Icon-Set
- Styles used: **Line Duotone** for default controls and **Bold Duotone** for selected/active states where available.
- SVG geometry is kept source-faithful; runtime tinting is applied by the Qt Quick icon pipeline.

Brand, protocol, cryptocurrency, and technology marks are intentionally kept outside Solar so their identity is not altered.
Consult the upstream repository for the current licensing and usage terms.
