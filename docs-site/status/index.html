Project invariants

Provider-neutral: No single vendor is the canonical data model. Local-first: known cached state can render without waiting for HTTP. Consent-aware: an extra service is not contacted without policy admission. Signer security: private signing material stays outside provider requests. Write correctness: pending writes remain attached to their original selected destination.
