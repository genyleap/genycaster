Prize entry conditions

Balaji requires MIT-licensed source, an independent human who has completed the tutorial, and a public endorsement. The existing Genycaster repository uses GPL-3.0, not MIT. A license change requires a separate rights review. The deadline is seven days after the original October 17 cast.

What can be verified now

The source repository includes contract tests for raw Snapchain reads, indexed reads, local storage, provider routing, signer and durable outbox handling, and WASM/QML UI guards. Tests certify their particular contracts, not an unavailable third-party service or complete node lifecycle.

See source tests and engineering design documents.

Prize-ready checklist

  1. Pin an immutable deployable node version and server-provisioning script.
  2. Automate an independent read-node bootstrap without third-party API keys.
  3. Prove read, follow, reaction and cast publishes using a validator and authorized app key.
  4. Demonstrate a safe existing-account app-key onboarding flow.
  5. Prove originating-client filters against verifiable message provenance.
  6. Publish real three-command acceptance tests and network trace.

Until all pass, present Genycaster as an advanced beta and a useful open engineering reference—not a completed $2,048 prize deliverable.
