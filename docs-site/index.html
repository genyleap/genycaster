What independence actually means

A different logo is not a different backend. Genycaster isolates protocol capabilities from vendor adapters and treats an external indexed API as optional infrastructure—not as the Farcaster protocol itself.

Precise claims, not shortcuts

Today: The public WebAssembly beta supports configured read-provider selection, optional compatible indexed fallback, localized navigation and some offline cached experiences. The architecture also contains distinct signed-write routes and durable provider affinity.

Not yet: Genycaster does not claim a fully verified zero-API-key, self-hosted end-to-end read/write experience or a secure three-command provisioning and seed phrase import tutorial. Those are explicit acceptance targets, not completed features.
